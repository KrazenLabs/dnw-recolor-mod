# Drag'n'Wash Recolor Mod

This mod lets you change the colors for the player character and the dragons on the fly ingame!
Pretty simple!

# Installation

- Make sure you have the most recent version of the DnW Mod Loader installed.
- Download the current version of the mod from the release page.
- Unzip the zip file into the "Mods" directory in your game directory (it should have been automatically created by the mod loader).

# Usage

Very straightforward: press F10 in-game to open the mod menu and simply adjust the sliders to your liking. The colors change in real-time and your selected colors will be automatically saved.

# How to uninstall

Simply deleted the "Recolor" directory within the "Mods" directory.
